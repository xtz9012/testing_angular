### 1. Install Dependencies

```bash
npm install
```

### 2. Install Playwright Browsers

```bash
npx playwright install
```

### 3. Verify Setup

```bash
npm run typecheck
```


### Run All Tests (Headless Mode)

```bash
npm test
```

Runs all tests with browsers hidden (fastest execution).

### Run Tests with Visible Browsers

```bash
npm run test:headed
```
